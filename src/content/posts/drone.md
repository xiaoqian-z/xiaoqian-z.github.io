## 一、制作前 你需要知道

先把一架**四旋翼**拆成两条线来看，后面所有章节都挂在这两条线上：

1. 四旋翼无人机？遥控？图传接收器？
2. 无人机的动力部分：电调？电机？桨叶？机架？电池？
3. 无人机的电控部分：飞控？2.4g elrs接收机？图传？摄像头？天线？
4. 无人机的保养部分：LiPo 平衡充电器？大功率烙铁？

- **动力线**（负责让它飞起来）：电池 → 电调 → 电机 → 桨叶
- **控制线**（负责让它听你的话）：遥控器 → 接收机 → 飞控 → 电调；摄像头 → 图传 → 眼镜/屏幕

![图片描述](/Drone/dronecontrolframe.png '电控部分接线与框架')

### 一个关键认知：飞控是大脑

飞控只做一件事——**根据姿态偏差，解算出四个电机各自该转多快**，然后把结果交给电调执行。所以：

- 姿态**感知**靠陀螺仪/加速度计（飞控板载）
- 姿态**修正**靠 PID 控制器（软件）
- 姿态**执行**靠电机转速差（硬件）

理解了这条链路，调试时才知道该改哪一层。

## 二、选型：买什么，为什么买它

选型的核心是**先定整机型格，再倒推零件**。5 寸是新手最合适的尺寸（配件多、教程多、抗风够用），不过为了**自身安全**，将会制作圈圈机，由于自己拥有3D打印机，可以直接打印3.5寸或者以下的的机架，因此选择3.5寸机来制作。

### 选型一致性检查

填完表才发现，选型最容易出错的地方不在单个零件，而在**零件之间对不对得上**。以下是待核实项：

- **显示端是屏幕，不是眼镜——制式必须对得上。** 小飞手四代内置 5.8G **模拟**接收，正好配蜗牛平头哥二代 + 旋风图传这条模拟链。
  - **天线要单独配。** 屏幕自带接收机，所以图传距离和花屏程度几乎全由屏上那根天线决定，随附的棒状天线通常很差，建议换成蘑菇头 + 平板的组合
  - **DVR 录的是收到的信号**，画质 = 你实时看到的画面（雪花也一起录进去）。它的价值不在清晰度，而在于**炸机后能回放**，还原最后一秒发生了什么
  - 用屏幕飞不是沉浸式 FPV，判断姿态和距离都比眼镜难。建议先目视飞行、屏幕只用来确认构图，熟练后再延展距离

- **3D 打印机架：拿"耐炸"换"可修"。** 我用 PETG 打印，外层圈圈是最先炸断的地方——但断了重新打一个就行，成本几乎为零，这是碳纤维机架给不了的。
  所以评价它的标准不是"结不结实"，而是**"断了要多久能回到天上"**。顺着这个思路有两个优化点：
  - 把易断的圈圈和机臂做成**独立零件**，断了只重打那一件，不用整机重来
  - 填充率降低可以减重，但机臂与机身连接处要保留强度

- **1W 图传的供电与散热。** 1W 发热很大，上电前**天线必须接好**，空载发射会烧功放；同时确认飞控的 BEC 能不能供得起。另外发射功率要符合国内微功率设备的规定。

## 三、组装：从裸机架到整机

按**从下往上、从后往前**的顺序，每一步只做一件事，做完拍照。

1. 机架组装（注意碳板方向、螺丝长度别顶穿电机）
2. 电机安装（四颗螺丝，长度必须小于电机定子厚度）
3. 电调焊接（电源线、三相线、信号线）
4. 飞控固定与接线
5. 接收机安装（天线远离碳板和电源线）
6. 图传与摄像头
7. **先不装桨叶**，等待通电测试

### 电调与电机的连接

将电机连接的三根线焊接好同时一定要固定到机架上，这是飞机稳定飞行的关键

### 飞控与电调的连接线

一般都是8p的sh1.0端子，这种东西手搓起来非常费劲，首先需要有远远小于1mm直径的导线，端子，同时自己做出来的线非常容易松脱，千万不要自制连接线，直接去购买，大概在0.5元一根，可以省下一大堆调试的时间

### 注意飞控的安装方向

一般的飞控上面都有一个三角形，这个有这个三角形的面需要指向天空，由于我制作的穿越机电机朝下，组装时也是倒置组装的，所以需要严格注意。这个三角形指向的方向是飞机默认的前方，由于我飞控螺丝间距20mm,需要斜着45度安装，所以需要在地面站里面将飞机机头朝向偏移45度匹配

### 串口的连接

基本上大部分模块和飞控的通信方式都是串口，一定要记住TX连接RX,这样交叉连接

### 接线与供电关系

![图片描述](/Drone/Dronewire.jpg '飞控接线')

### 焊接要点

烙铁功率一定要大，锡丝纯度不要使用45%，要比这个大一些，准备好毛刷擦掉锡珠

### 通电测试

通电后一般电调与飞控上面的LED灯会正常发光，同时一般电机就会一直哔哔地响（这个是正常现象，电调通电后前面三声是提醒电机连接正常，后面一直哔哔响就是飞控控制电调发出来的报警声音，因为你并没有连接elrs模块或者遥控连接elrs模块，不过没有关系，证明一切连接正常）。

## 四、软件配置（地面站）

### 飞控固件与地面站

使用了开源地面站Betaflight,直接插线就可以连接上，连接上以后一定要确认软件里面模拟出来的飞机和自己的动向一致，偏航角的偏移是看不出来的，需要通过俯仰和翻滚角度是否一致来判断偏航角是否同步（当然偏航角的偏移主要是和飞控上面三角方向与机头朝向有关）

### 端口（Ports）与串口分配

根据自己模块所连接的串口来分配，分配好elrs接收机，图传的串口以及灯带的IO

### 接收机绑定与协议（ELRS）

### 电机方向与转速协议

用数据线连接飞控，打开地面站，选择电机-调整电机顺序，确保没有连接桨叶以后根据指示设置好电机的顺序，
由于圈圈机电机朝下，所以要确保调节电机顺序时参考圈圈机正常飞行电机顺序。然后在调节电机的旋转方向

### 模式（Modes）（必须要配置好模式才能够试飞）

模式的作用是**把一个遥控器开关映射成一个飞控功能**：在 Modes 标签页里选中模式，指定一个 AUX 通道和一段区间，开关拨进去就生效。

Betaflight 里叫 **ARM（解锁 / 上锁）**。它和别的模式性质不一样——**它不是飞行模式，是安全闸门**：不解锁，油门推到底桨叶也不转。别的模式配错了顶多手感不对，ARM 配错了是安全问题。所以它是唯一一个"不配就不能飞"的模式。

#### 第一层：不配就有危险的

| 模式                      | 作用                                               | 配法                                       |
| ------------------------- | -------------------------------------------------- | ------------------------------------------ |
| **ARM**                   | 电机的总开关                                       | **单独占一个开关**，不要和别的模式共用区间 |
| **BEEPER**                | 炸机后蜂鸣器响，靠声音找飞机                       | 一个开关触发                               |
| **FLIP OVER AFTER CRASH** | 反乌龟：炸机翻倒后反转电机把飞机翻正，不用走过去捡 | 一个开关触发                               |

> 反乌龟有个前提：**飞机没卡住、桨叶完好**才能用。卡在树杈或草里硬转，会直接烧电调。

#### 第二层：飞行手感（按阶段挑一个）

- **ANGLE（自稳）** —— 摇杆回中自动回平，最大倾角受限（默认 55°）。**首飞就用这个**，松手飞机不会继续翻
- **ACRO（手动）** —— 飞控默认模式，纯角速度控制。摇杆回中**不**回平，飞机保持当前姿态。穿越机的标准模式，也是唯一能做出干净翻滚的模式
- **HORIZON（半自稳）** —— 小杆量自稳、大杆量切手动。过渡用，现在基本没人用了

**ANGLE 不是永久选项。** 习惯之后必须切 ACRO —— 在 ANGLE 下永远做不出翻滚，一直留在自稳就等于没学会真正的操控。

#### 第三层：这台机器能用上的

- **VTX PIT MODE** —— 把图传切到极低功率。**这台是 1W 图传，强烈建议配**：室内调参、地面测试时开着，避免 1W 近距离烤自己，也不干扰同场的其他人
- **LEDLOW** —— 降低灯带亮度（端口里已经分了灯带的 IO）。夜里飞或想省电时用
- **PREARM** —— 预解锁：要**同时**按住两个开关才能解锁，多一道防线。新手值得配
- **AIR MODE** —— 让油门在任何姿态下都有效，翻滚时不会掉高度。可以直接设成常开，不需要开关
- **FAILSAFE** —— 把失控保护**手动**触发一次。配个开关就能在不起飞的情况下验证失控保护到底有没有效，正好用在"首次通电与地面测试"那一步

**用不上的：** GPS RESCUE（返航）需要装 GPS 模块，这台没有。

#### 解锁不了怎么办

解锁时飞机没反应，八成是被**解锁保护**拦下了。Betaflight 的 **Setup 页面**会用黄字列出当前所有禁止解锁的原因，常见五种：

1. 油门没在最低位
2. 摇杆不在中位（遥控器微调没回零也算）
3. 接收机没信号 / 没对频
4. 加速度计没校准
5. **ARM 的开关区间配反了** —— 开关在"关"的位置反而落进了 ARM 区间

前四条是操作问题，第五条是配置问题。看到黄字就逐条排除，比反复插拔电池快得多。

## 五、对频

对频要做的是两件原理完全不同的事：**遥控对频是让接收机认得你的遥控器，图传对频是让屏幕收到图传发出的那个频点**。前者对上一次基本不用再管，后者换场地、多人一起飞时要经常改。

> 先分清两个词：**协议**决定"用什么方式说话"（Betaflight 端口里给接收机选 CRSF），**对频**决定"认不认得对方"。协议选错，怎么对都对不上。

### 遥控对频（ELRS）

现在 ELRS 基本靠 **Bind Phrase（加密短语）** 绑定，不需要按接收机上的按键：

1. 遥控器的 ELRS 菜单里设一个自己的 Bind Phrase
2. 把**一模一样**的短语写进接收机（Betaflight CLI 或 ELRS 配置工具都可以）
3. 两边上电，接收机灯常亮 = 绑定成功

要手动对频就用「**三次上电法**」：接收机断电、上电，连着做三次，第三次之后进入绑定模式；同时遥控器在 ELRS 菜单里点 Bind。

绑不上时按这个顺序查：

- **Bind Phrase 打错了** —— 最难查的一个，错一个字符就绑不上，而且不会报任何错
- **频段不对** —— 接收机是 915MHz 的，配 2.4G 高频头永远对不上
- **固件大版本不一致** —— ELRS 2.x 和 3.x 的绑定方式不一样，两边要对齐

**绑定成功后先别急着装机去飞。** 去 Betaflight 的**接收机页面**拨一下摇杆，看四个通道条是否跟着动、方向对不对。这一步能一次性查出绑定失败、协议选错、通道映射错三类问题，比上天之后再发现便宜得多。

### 图传对频

模拟图传的频点由**频段（Band）+ 频道（Channel）**决定，常见 5 个频段（A / B / E / F / **Raceband**），每段 8 个频道。**图传发射端和屏幕接收端必须落在同一个频点上**，错开了就只剩雪花。

改频点按省事程度排：

1. **OSD 菜单改**（最常用）—— 摇杆进菜单直接切。但前提是 Betaflight 里的 **VTX Table 已经配好**，表不对，菜单里显示的频点就是错的
2. **图传自带按键** —— 直接按图传上的键切换
3. **地面站改** —— 接 USB 在线改

单飞和多人飞的策略不一样：

- **自己飞**：随便挑个频点，功率调到刚好覆盖活动范围就行。1W 没必要，白白费电发热
- **多人飞**：必须**错开频点**，一般按 Raceband 依次分配，相邻两人至少隔一个频道。同频点会互相串台，谁信号强谁盖住谁

**上电前必须确认天线已经接好。** 1W 图传空载发射会烧功放，这是整机最贵的一次性错误。

## 六、首次通电与地面测试

**这一步比首飞更危险，必须按顺序来：**

1. 用万用表通断档确认电源正负极**没有短路**
2. 通过 smoke stopper / 限流电源上电，只看电流
3. 连接地面站，确认陀螺仪、加速度计数据正常
4. 三个方向晃动飞机，确认姿态动画方向**一致**
5. 装桨叶前，确认电机转向正确（用地面站单独测试每个电机）
6. 确认失控保护、解锁开关、蜂鸣器都有效

## 七、首飞

- 场地选择（空旷、无人、远离机场与人群）
- 首飞只做：低空悬停 → 微调 → 简单航线
- 记录项：飞行时间、电池电压回落、电机温度、是否有异常抖动

## 八、故障排查

| 现象                | 可能原因                     | 排查步骤 |
| ------------------- | ---------------------------- | -------- |
| 上电不亮 / 冒烟     | 电源短路、极性接反           |          |
| 电机不同步 / 咔哒声 | 电机协议、焊接虚接           |          |
| 起飞即翻            | 电机转向、桨叶装反、飞控方向 |          |
| 悬停漂移严重        | 加速度计校准、机架震动       |          |

| 图传花屏            | 天线、频点冲突、供电         |          |

## 九、安全与法规

- 实名登记（按《无人驾驶航空器飞行管理暂行条例》执行）
- 禁飞区 / 限高查询
- 电池安全（充放电、存放、鼓包处理）
- 桨叶永远是最后装、第一拆
